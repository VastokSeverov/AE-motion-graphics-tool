# VASTOCHNIY AE Copilot — macOS setup

This build has **one action only: Remove Background** for a selected local still image. It runs locally on your Mac; no API key is required. Video is not supported yet.

## 1. Install the bridge dependencies

From the repository root:

```bash
cd ~/Downloads/AE-motion-graphics-tool
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements-background.txt
python server/server.py
```

Keep the Terminal window open. The bridge listens only on `127.0.0.1:8766`. If the port is already in use, stop the old bridge with Ctrl+C in its Terminal window before starting this one.

The first background-removal run downloads the model and can take several minutes. The Terminal prints processing details and errors.

## 2. Install the CEP panel

1. Quit After Effects.
2. Copy the contents of the repository's `cep` directory into:
   `~/Library/Application Support/Adobe/CEP/extensions/com.vastochniy.aecopilot/`
3. Make sure `index.html`, `panel.js`, `CSXS/manifest.xml`, and `jsx/host.jsx` are inside that folder.
4. Start After Effects and open **Window → Extensions (Legacy) → VASTOCHNIY AE Copilot**.

If this extension has not been installed before, Adobe's unsigned CEP extension setting may be required for your After Effects version. Only enable it for development.

## 3. Use it

1. Open a composition.
2. Select exactly one local still-image layer (PNG, JPG/JPEG, WEBP, TIFF, or BMP).
3. Click **Remove Background**.
4. Wait for the transparent PNG to be generated and imported.

The original image file is never overwritten. The selected layer is switched to the transparent PNG; its layer transforms and timing should remain. Use Undo to restore the original source.

## Troubleshooting

- **Bridge offline:** activate `.venv` and run `python server/server.py`; check the Terminal for startup errors.
- **Port already in use:** stop any old bridge process before restarting.
- **Background remover not installed:** run `python -m pip install -r requirements-background.txt` with `.venv` activated.
- **Model download/inference error:** inspect the bridge Terminal for the detailed error.
- **After Effects scripting error:** restart After Effects and confirm the installed extension folder contains the updated `jsx/host.jsx`.
- **Selected layer error:** only one saved still image can be processed. Footage must be online and stored locally.

The bridge intentionally exposes only the background-removal endpoint. No other Copilot actions are available in this build.
